# [이슈] 리프트 서보를 연속회전형으로 착각해 생긴 시험 혼선

- 날짜: 2026-11-21
- 영역: forklift / 리프트 서보 (FT6325M), 시험 스케치 `firmware/tests/pca9685_servo_test`
- 상태: 원인 확인됨, 후속 작업 남음

## 요약

리프트 서보를 MG996R에서 FT6325M으로 바꾸면서 "360° 다 도는 서보"를 **연속회전형**(펄스 = 속도)으로 이해했다. 그런데 실제로는 **위치 제어형**(펄스 = 각도)으로 동작했다. 이 착각 때문에 서보가 "조금 감겼다 풀렸다" 하는 이해하기 어려운 동작이 나왔고, 시험 스케치와 문서를 두 번 고쳤다.

## 배경

- 문서상 리프트 서보는 MG996R(위치 제어형)이었다. 시험 스케치도 위치형 기준(펄스 폭 = 각도)으로 작성했다.
- 시험 도중 실제 장착된 서보가 FT6325M이라는 사실과 "360° 다 돈다"는 설명이 나왔다.
- 이를 **연속회전형**으로 해석해 스케치와 문서를 바꿨다. 연속회전형은 약 1500µs가 정지이고, 그보다 크거나 작으면 그 방향으로 계속 돈다.

## 경과

| 순서 | 한 일 | 관찰 |
|---|---|---|
| 1 | 위치형 스케치로 1500 → 1600 → … → 2000µs 이동 | 아주 미미하게만 움직임. 줄은 계속 느슨함 |
| 2 | "360° 서보"라는 말을 듣고 연속회전형으로 판단. 2000µs(최고 속도로 계속 회전한다고 가정)가 위험하다고 보고 출력 OFF | — |
| 3 | 문서와 스케치를 연속회전형으로 수정: 정지점 1500µs, 시간 제한 회전, 키보드 조종(`w` 누르는 동안 회전, 떼면 1500µs 정지) | — |
| 4 | `w`를 꾹 누름 | **조금 감기고 → 조금 풀리고 → 조금 감기고 → 멈춰서 버팀** |
| 5 | `w`를 뗌 | **다시 조금 풀림** |
| 6 | 4~5를 위치형 동작으로 판정. 스케치를 위치형(누르는 동안 각도 증가, 떼면 유지)으로 다시 쓰고 문서 정정 | 감김/풀림 반복이 사라짐 |
| 7 | 줄을 팽팽하게 하려고 소프트웨어 한계를 1000~2000 → 500~2500 → 100~4000µs로 넓힘 | 500~2500µs에서도 360°를 다 돌지 못하고 끝에 닿음 |
| 8 | 100~4000µs에서 양 끝 확인 | 감는 쪽 2900µs, 푸는 쪽 100µs에서 더 돌지 않음 → 범위 100~2900µs로 확정 |

## 원인

1. **"360° 서보"라는 표현이 두 종류를 가리킨다.**

   | | 연속회전형 | 360° 위치형 |
   |---|---|---|
   | 펄스 폭 | 속도·방향 | 각도 |
   | 회전 | 몇 바퀴든 | 최대 한 바퀴, 양 끝 있음 |
   | 멈추면 | 버티지 않음 | 그 각도를 버팀 |

2. **서보 종류를 실물로 확인하지 않고 코드를 짰다.** 서보는 위치형인데, 스케치는 연속회전형 기준이었다. 그 상태에서는 다음과 같이 동작한다.
   - `w` 입력: 1700µs → 그 **각도로 이동** (감김)
   - 키 반복 전 0.3초 경과: "정지" 1500µs → **원래 각도로 복귀** (풀림)
   - 키 반복 시작: 다시 1700µs (감김) → 도착 후 버팀
   - 키를 뗌: 1500µs → 원래 각도로 복귀 (풀림)

   1번 단계에서 "미미하게만 움직였다"는 관찰도 위치형이면 설명된다. 정해진 각도까지만 가고 멈추기 때문이다.

3. **시험 스케치의 소프트웨어 한계가 처음에 너무 좁았다** (1000~2000µs). 위치형 서보를 조심스럽게 시험하려는 의도였지만, 줄을 팽팽하게 만드는 게 목적이었으므로 처음부터 서보의 전체 범위를 열었어야 했다.

## 알게 된 것

- **위치형 서보는 기준점을 바꿀 수 없다.** 몇 µs가 몇 도인지는 서보 내부 각도 센서가 정한다. "지금 위치를 0으로" 같은 초기화는 서보에서는 불가능하다. 소프트웨어에서 상대값으로 표시하거나, 기구(줄 묶는 위치, 혼 장착 각도)로 맞춰야 한다.
- **위치형은 리프트 높이에 한계가 있다.** 감을 수 있는 줄 길이 = 드럼 둘레 × (회전 범위 / 360°). 줄이 느슨하면 그 여유를 감는 데 회전 범위를 써 버린다.
- **장점도 있다.** 위치형은 하중을 건 채 멈춰도 스스로 버틴다. 연속회전형이었다면 포크가 하중으로 내려가는 문제를 따로 해결해야 했다.

## 재발 방지

- 서보를 새로 달거나 바꾸면, 코드를 쓰기 전에 **종류부터 실물로 확인**한다.
  - 확인 방법: 혼을 뗀 상태에서 1500µs를 준 뒤 2000µs를 몇 초간 준다.
  - 조금 돌고 멈춰서 버티면 위치형, 계속 돌면 연속회전형이다.
- 부품 사양을 적을 때 "360°"처럼 뜻이 둘인 표현 대신 **"연속회전" / "위치 제어(범위 ○○°)"**로 쓴다.
- 문서의 결정 사항과 실물 부품이 다르면 시험 전에 문서부터 맞춘다. 이번에는 문서가 MG996R인데 실물은 FT6325M이었다.
