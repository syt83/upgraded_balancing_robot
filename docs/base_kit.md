# 베이스 키트 (KS0193) 공통 정보

## 하드웨어

- 메인 보드: Keyestudio V4.0 (Arduino UNO 호환). 칩 이름은 공식 문서에 없으나 UNO용 라이브러리를 쓰므로 ATmega328P로 추정.
- 쉴드: Keyestudio Balance Shield V3. 모터 드라이버 TB6612FNG, 자세 센서 MPU-6050, XBee 형태 블루투스 소켓(HC-06), 전원 슬라이드 스위치, 블루투스 시리얼 슬라이드 스위치, 부저, 버튼(KEY_13).
- 모터: GM37-520 홀 엔코더 DC 기어모터 ×2, 12V, 1:30, 무부하 247rpm, 정격 토크 1.4 kg·cm, 정지 토크 5.5 kg·cm, 정지 전류 2.4A.
- 전원: 3셀 18650 홀더(완충 약 12.6V). 키트 문서상 동작 전압 9~12V.
- 블루투스: HC-06 (클래식 SPP, 안드로이드 전용, 9600baud).
- 코드 업로드 시 쉴드의 블루투스 슬라이드 스위치 OFF, 블루투스 사용 시 ON. HC-06이 USB와 같은 하드웨어 UART(D0/D1)를 공유하기 때문.

## 핀 사용 (키트 예제 코드 기준)

| 기능 | 핀 |
|---|---|
| 오른쪽 모터 방향 / PWM | D8, D12 / D10 |
| 왼쪽 모터 방향 / PWM | D7, D6 / D9 |
| 엔코더 A상 (왼쪽 / 오른쪽) | D5 / D4 |
| 부저 / 버튼 | D11 / D13 |
| MPU-6050 | I2C (A4 SDA, A5 SCL) |
| HC-06 | 하드웨어 시리얼 D0, D1 |

- D9, D10 PWM은 Timer1.
- 엔코더는 A상만 읽고, 회전 방향은 모터 PWM 부호로 추정.
- 비어 있는 핀: D2, D3, A0~A3 정도. D3 PWM은 Timer2(MsTimer2) 때문에 영향을 받음.

## 제어 구조

- MsTimer2(Timer2)로 5ms 타이머 인터럽트. 그 안에서 MPU-6050 읽기(I2C), 칼만 필터, 각도 PD 제어, 모터 PWM 출력.
- 속도 PI 제어 40ms, 조향 PD 제어 20ms 주기.
- 엔코더는 PinChangeInt 라이브러리로 읽음.
- 앱 명령은 한 글자 문자(F/B/L/R/S 등), 일부 문자는 PID 값 조정용.
- 기울기 ±80° 초과 시 모터 정지.

## 미확인 사항

- 엔코더 PPR과 출력 전압.
- 쉴드 핀아웃 세부(TB6612FNG PWMA/PWMB ↔ D9/D10 대응, STBY 연결). 공식 핀아웃이 이미지라 확인 못 함.
- 쉴드 시리얼 핀 헤더가 블루투스 슬라이드 스위치의 영향을 받는지.
