# Upgraded Balancing Robot

keyestudio KS0193 Self-balancing Car Kit(2륜 밸런싱 로봇)을 베이스로 한 두 개의 독립 프로젝트.

| 프로젝트 | 내용 |
|---|---|
| [forklift/](forklift/) | 차체 앞에 줄 감기식 리프트 포크를 단 밸런싱 지게차. 안드로이드 앱(HC-06) 조종, ESP32-CAM 영상 |
| [line_tracking/](line_tracking/) | 라인 트래킹 |

두 프로젝트는 서로 코드를 공유하지 않는다. 공통 베이스 키트 정보는 [docs/base_kit.md](docs/base_kit.md)에 있다.

작업 전에 [CONTRIBUTING.md](CONTRIBUTING.md)(작업 지침)를 읽는다.
